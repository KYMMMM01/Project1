# 사용자 지시 묶음 (2026-10-09 밤) — 원문과 해석

배포본 상태: `main` = v1.3 규칙 + 보스 방어/저항(체력 그대로). 보류 브랜치 `wip/balance-2`(커밋 `d8abeca`)에 버프 표시(완성)와 마법 너프·재주 버프(미완)가 있다.

## 원문 (사용자)

1. 총잡이냥 문구 "치명타 피해 3배"로 바꿔줘. 이런 비슷한 것들도 다, 치명타 배수도 **치명타 피해량**으로 표기 바꿔주고.
2. 전사 추가 버프는 취소하고.
3. 악사냥이 피해량 증가 5% 너프 먹이는 대신 주변 1칸 범위로 8칸.
4. 방울냥 젖음/낙뢰 확정 면역이 아니라 확률적으로 피하는 식으로 너프, 대신 주변 1칸 범위로 8칸.
5. 사무라이냥 특기 너프(출혈 딜 주기나 피해량 너프, 범위 너프).
6. 번개냥이에 감전 효과 추가(0.3~0.5초).
7. 별빛 사수 특기 => 관통 1마리, 범위 90, 피해량 25%. 피해량을 30 줄이고 공격 간격을 0.5초로 버프.
8. 요리사냥이랑 방울냥 위치 바꾸기.
9. 1성은 시너지에 포함 안 되게 해서 수호자까지 뽑아야 4종 시너지를 켤 수 있게 하고, 3종 시너지까지는 기존보다 조금 너프, 대신 4종 시너지에 4종 시너지만의 특수 능력(직업군마다 다름)을 넣어주는 식 => 각성에 필요한 조건인 시너지 개수는 완화하는 식으로.
10. 또한 시너지에 있는 직업 계열 피해는 두고, 방어 무시·상태 이상 지속과 같은 부가 효과들은 **전체 적용**으로 변경. 사수는 4종 이상 기준으로 사수 피해 +n%(해당 직업만), 치명타 확률 20%에 치명타 데미지 10%(전체 적용)로 변경. 그 아래 시너지 수치는 너가 잘 정해줘. 재주 시너지는 그대로.
11. 골드 수급용 일일 던전 만들기.
12. 레이저에 보스 우선 타격 넣고 지속시간 1~2초 버프.
13. 올라간 방어력에 맞춰 보스 체력 10%씩 너프.
14. 테스트용으로 골드 추가하는 버튼 추가.
15. 재주는 버프 취소하고 버프 표시만 추가하는 쪽으로.
16. 칸은 5x5로 늘리기.
17. 마법 유틸 너프 쪽: 블랙홀은 아까 그대로(끌어당김 거리 축소 + 한 번 끌린 적은 일정 시간 면역 + 보스·정예는 훨씬 덜 끌림). 빙결: 풀린 뒤 잠깐은 다시 얼지 않게, 대신 빙결 확률 버프. 둔화는 일단 이전 그대로 유지.

이전에 확정된 것 중 유지: 사무라이냥 피해 소폭 너프(5번과 합쳐 처리), 재주 고양이 자체 피해 너프는 15번("재주는 버프 취소")으로 대체되어 **하지 않는다**(재주 수치는 3·4·8번 외에는 그대로).

## 해석 (Claude, 다르면 사용자가 정정)

- 3·4번: 오라 범위 = 자기 칸을 둘러싼 8칸(대각선 포함). 악사냥의 피해 증가 수치는 5%p 낮춘다. 방울냥의 젖음·낙뢰 면역은 확률 회피로(확률은 등급 보정 포함해 정함).
- 7번: 별빛 사수 = 화살이 적 1마리를 더 관통, 처치 시 폭발 반경 90·본 피해의 25%. 기본 피해 250 → 220, 공격 간격 0.8 → 0.5초.
- 8번: 재주 줄에서 방울냥(꼬마)과 요리사냥(동네)의 **등급 자리를 맞바꾼다**(요리사냥 = 꼬마, 방울냥 = 동네). 수치는 새 등급에 맞게 조정. 그림은 그대로라 등급 사다리 복장 규칙(꼬마 = 장난감 장비)과 어긋날 수 있음 → 필요하면 나중에 다시 그림.
- 9번: 시너지에 세는 종류 = 동네·골목대장·대왕·수호신(꼬마 제외). 2종/3종 = 1/2단계(수치 소폭 하향), 4종(수호신 포함) = 3단계 + 직업별 고유 능력. 각성 조건의 시너지 요구는 2단계 → 1단계(2종)로 완화.
- 10번: 직업 피해 보너스는 그 직업만, 부가 효과(전사 방어 무시, 마법 상태 이상 지속, 사수 치명 확률·치명 피해)는 보드의 모든 고양이에게. 사수 3단계 = 사수 피해 +n%(사수만) + 치명 확률 +20%p·치명 피해 +10%(전체). 재주 시너지는 변경 없음.
- 11번: 하루 입장 횟수가 있는 "골드 던전" 모드(짧은 판, 성과에 따라 골드 지급, 홈 출동 탭에 카드). 세부 설계는 구현 담당이 메타 규칙에 맞춰 정하고 명세에 기록.
- 12번: 레이저가 켜져 있는 동안 범위 안의 보스·정예를 최우선 타깃으로, 지속 5 → 6.5초.
- 13번: `BOSS_HP` 표 ×0.9(정예 체력은 그대로).
- 14번: 테스트 빌드용 "골드 +10,000" 버튼을 설정 화면 맨 아래 "테스트" 구역에(정식 출시 빌드에서는 숨김: 개발 플랫폼(`VITE_PLATFORM` 미지정/dev)에서만 표시).
- 16번: 보드 5열 × 5행(25칸). 720 × 1280에 들어가도록 칸 높이를 줄이고 전장·HUD 배치를 다시 맞춘다. 햇살 칸 수, 자리 효과 장난감(바깥 테두리 14칸 → 16칸 등), 튜토리얼 좌표, 봇 배치도 함께.
- 밸런스: 사용자가 직접 플레이하며 조정 중이므로, 지시된 것 외의 체력·난이도 재조정은 하지 않고 봇 수치는 전후 비교로 보고만 한다.
