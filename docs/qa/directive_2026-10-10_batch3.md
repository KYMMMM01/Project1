## 해석 (Claude, 다르면 사용자가 정정)

- 1: 은·금 상자 카드에 "10개 사서 열기" 가격표. 가격은 정확히 10배(1,500 / 5,000 보석), 할인·덤 없음. 확인 팝업 → 한 번에 결제 → 10개 한번에 열기. (`main` 작업 폴더에서 워크플로 `shop-buy-ten`이 진행)
- 2: 시즌 패스 탭이 계정 4레벨에 열리던 조건을 없애고, 고양이 탭과 같이 첫 판(튜토리얼)을 마치면 열리게 했다(`FEATURE_RULES.pass = { runs: 1 }`). 설명서 문구·명세·테스트 반영. (브랜치 `balance-1010` 커밋 `504bbfa`)
- 3: 일반 적(정예·보스 아님)에게 **물리 방어**를 5~10% 준다. 마법 저항(결계)은 그대로.

  | 적 | 방어 이전 → 이번 | 비고 |
  |---|---|---|
  | 먼지 뭉치(dust), 물방울(drop), 꼬마 풍선(balloon_small) | 0 → 5% | 작고 빠른 쪽 |
  | 오이(cucumber), 풍선(balloon), 귤(tangerine), 넥카라(cone) | 0 → 8% | 귤의 결계 35%는 그대로 |
  | 알람시계(clock), 약병(pill), 드라이기(dryer) | 0 → 10% | 지원형 |
  | 로봇청소기(roomba) | 35% 그대로 | 이미 갑옷 적 |
  | 정예(분무기·폭죽·대왕 오이), 보스 | 그대로 | |

- 4: 적마다 **둔화 저항**(0~1) 수치를 새로 둔다. 걸리는 둔화 = min(둔화량 × (1 + 장난감 보정), 상한) × (1 − 둔화 저항). 상태 이상 "둔화"에만 적용(빙결·기절·끌어당김·장난감의 전체 감속은 그대로).

  | 적 | 둔화 저항 | 이유 |
  |---|---|---|
  | 물방울(drop) | 30% | 빠른 돌파형: 둔화로만 묶어 두기 어렵게 |
  | 알람시계(clock) | 30% | 가속 오라를 뿌리는 우선 처치 대상 |
  | 로봇청소기(roomba) | 20% | 묵직한 갑옷 적 |
  | 그 밖 | 0 | 정예·보스는 지금도 둔화 상한이 25%(일반 50%) |

- 표시: 도감 몬스터 목록·상세에 방어 수치가 이미 나오므로 새 수치가 그대로 보이고, 둔화 저항은 도감 상세(와 목록 줄)·전투 중 적 설명 말풍선에 추가한다. 새 특성(trait) 아이콘은 만들지 않는다.
- 난이도: 지시된 것 외의 재조정은 하지 않고, 봇 수치는 전후 비교로 보고만 한다.
