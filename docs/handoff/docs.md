## 내가 정한 것 (명세에 없어서 판단한 부분, 뒤집어도 된다)

1. 챕터 해금은 "앞 챕터 단계 0 클리어", 단계 n+1은 단계 n 클리어로 연다. 소탕·일일 도전·무한의 해금은 "챕터 1·2 클리어"로 맞췄다.
2. 은/금 상자 획득처: 별을 없앤 자리에 챕터 단계 0 첫 클리어 = 금 상자, 단계 1~5 첫 클리어 = 은 상자를 넣었다(메타 명세 v0.9의 "보통은 금·그 밖은 은" 규칙을 옮김).
3. 훈련소는 `laser_cd`(규칙 명세 §8이 가리킴)를 7번째 항목으로 추가하고 `enemy_cap`은 존치했다. 골드 sink 합계는 "약 137만"에서 "약 140만"으로 고쳤다.
4. 한 판의 골골은 "약 20"(막 클리어 2 × 5~6 + 보스 2 × 3 + 정예 1 × 3)으로 적었다. 마지막 막 클리어에 +2가 붙는지는 명세에 없다.
5. 튜토리얼 타임라인의 초 단위, 튜토리얼이 거실 챕터(정예 대왕 오이 4웨이브, 보스 흡입왕 8웨이브)라는 가정, HUD 단계 공개의 판별 배치는 규칙 명세 시간 값으로 계산했다.
6. 보스 예상 처치 시간 색 경계(제한시간의 2/3, 11/12)는 비평의 60초 기준(40 / 55초)을 제한시간 비율로 옮긴 값이다.
7. 효과음 "약 70종"은 `src/audio/api.ts`의 현재 목록 수다.
8. 골드 보상식에 "집사 난이도 단계 보너스"를 넣었다(값은 메타 명세가 정한다).

## 알려진 틈

- 메타 명세(`docs/명세_메타.md`, v0.9)가 기획서 §7과 어긋난다(아래 REQUESTS 1). 기획서가 최신이다.
- 결정 기록의 근거 수치는 비평자의 종이 모델이다. `npm run sim`이 나오면 D-05·D-06·D-11·D-17·D-18의 숫자를 교체해야 한다.
- 비평 원문은 저장소 밖에 있다. 결정 기록 끝의 "인용한 비평 발견" 표가 번호와 제목만 담는다. 원문을 저장소에 넣을지는 정해야 한다.
- 선행작 대조(§17.1)는 리서치 문서의 메카닉 표만 근거다. 화면 1:1 대조는 하지 않았다.
- 결정 기록 G에 적은 7개 제안은 "규칙 명세에 없음"이라고만 적었고, 채택하지 않은 이유는 모른다.
