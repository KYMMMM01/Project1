### 1.1 왜 이 게임이 돈이 되는가 (근거 요약)

- 한국 모바일 Action&Strategy에서 타워 디펜스가 2026-02 다운로드 1위. 운빨존많겜은 출시 2개월에 300만 DL·$2,000만, 2025-04 누적 1,200억 원 이상 — **장르 수요가 검증됨** (레퍼런스 분석 §1, §3.1.3).
- 그러나 상위작은 대규모 UA 위에서 성장했고(111% 2024 광고선전비 396억 원) 전부 **협동/PvP 중심**이다. 리뷰의 반복 불만은 "싱글 옵션이 없다", "확률을 못 믿겠다", "과금 벽", "후반 HP 인플레" (§3.1.4). → **싱글·공정·짧은 런**이 비어 있는 자리다.
- 수익화·유통 분석의 장르 비교에서도 1순위는 "랜덤 소환 머지 디펜스 + 방치형 성장 메타, PvE·솔로 범위"였다(§A-5). 가장 강한 반론은 "검증된 대형 매출이 사실상 한 회사 계보(n=1)이고 가챠·라이브옵스 의존이 크다"는 점이며, 본작은 유료 가챠 없이 시작하고 콘텐츠를 데이터 주도로 설계해 이 위험을 줄인다.
- 1인 개발의 병목은 ARPDAU가 아니라 **DAU 확보**다(§A-6). 유료 UA 없이 열려 있는 유입 경로는 **토스 앱인토스**(사용자 3,000만, 머지형 RPG가 무마케팅으로 70일 100만 다운로드)와 **웹 포털의 오가닉 트래픽**이다. 빌드는 처음부터 채널 SDK를 갈아 끼울 수 있게 추상화한다(§14).
- 수익 가늠(분석 §A-6, 추정): DAU 5,000 기준 광고만으로 월 약 $4.5K~15K, IAP를 더한 하이브리드로 월 약 $22K~75K(수수료 차감 전). 한국은 매출의 77~90%가 IAP이므로 토스·스토어 빌드는 IAP가 주 수익원이다.
- 2026-04 서울중앙지법 판결(2024가합115708): 메카닉은 보호되지 않지만 **결합 패키지와 핵심 성장 구조를 통째로 닮게 만들면 부정경쟁**(약 5.6억 원 배상). 따라서 본작은 보드 구조·합성 규칙·성장 메커니즘·재화 체계·화면 구성을 **독자 설계**한다(§17).

## 2. 디자인 기둥

1. **운은 재밌게, 결과는 믿을 수 있게** — 모든 확률을 화면에 띄우고, 천장(pity)을 숫자로 보여주며, 런 시드를 공개한다. 운이 나빠도 다음 수가 있다(골라 뽑기·행운 캡슐·판매).
2. **30초마다 작은 기쁨, 5웨이브마다 큰 선택** — 소환·합성의 손맛이 기본 박자, 막(5웨이브) 끝의 장난감 3택이 빌드의 방향을 바꾼다.
3. **자리와 조합이 실력** — 사거리·인접 버프·직업 시너지로 "어디에 누구를 둘지"가 승패를 가른다.
4. **연출은 중요도에 비례** — 흔한 일은 가볍게, 드문 일(전설·신화·보스)은 크게. 연출이 입력을 막지 않는다.
5. **힘이 아니라 시간과 편의를 판다** — 결제 없이 모든 콘텐츠에 도달한다. 광고는 전부 선택형이다.

## 3. 코어 루프

```
[전투 한 판] 생선으로 소환 → 드래그로 배치·합성 → 직업 시너지 완성 → 막 클리어마다 장난감 3택
      → 전설을 신화로 각성 → 30웨이브 보스 격파
            ↓ (골드·카드·패스 XP·상자)
[메타] 유닛 카드로 레벨업 · 훈련소 강화 · 챕터/난이도 해금 · 미션/출석/시즌 패스 · 순찰 보상
            ↓
      더 어려운 챕터·무한 모드·일일 도전
```

### 3.1 전장

- **보드**: 러그 위 **5열 × 4행 = 20칸**, 한 칸에 유닛 1마리. (운빨존많겜의 3×6·칸당 스택 구조와 다르다.)
- **경로**: 러그 둘레의 마룻바닥을 **시계 방향으로 도는 루프**. 적은 죽을 때까지 계속 돈다.
- **패배 조건**: ① 필드의 적 수가 **한도(기본 60)를 넘으면** 패배, ② 보스를 **제한시간 안에 못 잡으면** 패배.
- 경고 단계: 적 40마리 이상 "주의"(HUD 게이지 주황), 50마리 이상 "위험"(가장자리 붉은 비네트 + 심장박동음).

### 3.2 소환

| 항목 | 초기값 |
|---|---|
| 시작 생선 | 100 |
| 소환 비용 | `12 + 4n` (n = 이번 판 소환 횟수), **상한 80** |
| 기본 등급 확률 | 일반 70% / 희귀 25% / 영웅 5% / 전설 0% |
| 직업 | 4직업 균등(각 25%) |
| 배치 | 빈 칸 중 무작위 한 칸에 떨어진다. 빈 칸이 없으면 소환 불가(버튼에 "자리 없음") |

- **행운 강화**(생선 소비, 5단계): 단계마다 일반 −6%p, 희귀 +3%p, 영웅 +2.4%p, 전설 +0.6%p → 최대 40 / 40 / 17 / 3.
- **천장(pity)**: 일반이 **7번 연속**이면 다음은 희귀 이상 확정. 영웅 이상이 **12번** 안 나오면 이후 소환마다 영웅 이상 확률 **+3%p** 누적(나오면 초기화). 두 카운터는 소환 버튼 옆에 항상 표시한다.
- **골라 뽑기**: **6번째 소환마다** 후보 3마리(각자 등급 굴림, 최소 희귀)를 보여주고 1마리를 고른다. 고르는 동안 전투는 멈춘다. 소환 버튼의 발자국 6칸이 진행도를 보여준다.
- **확률 보기**: 소환 버튼 위의 `%` 칩을 누르면 현재 확률표(행운 강화·장난감 반영)와 천장 상태가 뜬다.

### 3.3 합성과 각성

- **합성**: 유닛을 **같은 종류** 유닛 위로 끌어다 놓으면 둘이 사라지고 **한 등급 위의 무작위 유닛**이 그 칸에 나온다(일반→희귀→영웅→전설).
- **신화 각성**(본작의 핵심 성장 구조):
  - 전설 유닛은 자기 **직업 시너지가 2단계(5마리)** 이면 🍀 클로버 3개로 **그 직업의 신화**로 각성한다(유닛 정보 카드의 "각성" 버튼).
  - 같은 전설 2마리를 합성해도 그 직업의 신화가 된다(클로버 불필요).
  - 신화는 직업당 1종(총 4종). 신화끼리는 합성하지 않는다.
- **이동/교환**: 빈 칸으로 끌면 이동, 다른 종류 위로 끌면 자리 교환. 비용 없음.
- **판매**: 드래그 중 화면 아래에 나타나는 판매 구역에 놓는다. 환급: 일반 6 / 희귀 18 / 영웅 55 / 전설 170 생선, 영웅 이상은 🍀 +1.

### 3.4 직업과 시너지

보드 위 같은 직업의 **마릿수**로 발동한다(3 / 5 / 7마리). 하단의 직업 칩 4개가 현재 마릿수와 단계를 항상 보여준다.

| 직업 | 역할 | 사거리 | 3마리 | 5마리 | 7마리 |
|---|---|---|---|---|---|
| ⚔️ 전사 | 물리 근접·광역, 방어 깎기 | 짧음(바깥 줄에 배치) | 전사 피해 +25% | +60%, 방어 30% 무시 | +120%, 방어 60% 무시 |
| 🏹 사수 | 물리 원거리 단일, 치명타 | 김(어디든) | 사수 치명 확률 +12%p | +25%p, 치명 피해 +50% | +40%p, 치명 피해 +120% |
| 🔮 마법 | 마법 광역, 둔화·화상·연쇄 | 중간 | 마법 피해 +25% | +60%, 상태이상 지속 +40% | +120%, 상태이상 지속 +80% |
| 🎁 재주 | 인접 버프, 경제, 약화 | 중간 | 전 아군 공속 +8% | +16%, 웨이브 보상 +20% | +28%, 웨이브 보상 +50% |

- **인접 버프**: 재주 직업의 오라는 상하좌우 4칸에만 닿는다 → 가운데 칸의 가치가 생긴다.
- 넓게(3마리 시너지 여러 개) 갈지, 깊게(한 직업 5~7마리 + 각성) 갈지가 매 판의 핵심 선택이다.

### 3.5 웨이브와 막(Act)

| 항목 | 초기값 |
|---|---|
| 구성 | **6막 × 5웨이브 = 30웨이브** |
| 일반 웨이브 | 16초(스폰은 앞 10초). 타이머가 끝나면 남은 적과 무관하게 다음 웨이브 시작 |
| 막의 마지막 웨이브 | 5·15·25웨이브 = **정예**(제한 45초), 10·20·30웨이브 = **보스**(제한 60초). 처치 즉시 웨이브 종료 |
| 막 클리어 | 전투 정지 → **장난감 3택** → 🍀 +2, 생선 보너스 → 다음 막 |
| 다음 웨이브 예고 | HUD에 다음 웨이브의 적 아이콘과 특성(갑옷·결계 등) 표시 |
| 배속 | 1× / 2× (두 번째 판부터 무료 해금), 언제든 일시정지 |

### 3.6 인런 경제

- 🐟 **생선**: 적 처치(일반 1, 정예 15, 보스 60), 웨이브 클리어 보너스 `18 + 2×웨이브`. 용도: 소환, 직업 강화, 행운 강화.
- 🍀 **클로버**: 막 클리어 +2, 보스 +3, 정예 +1, 영웅 이상 판매 +1. 용도: 행운 캡슐, 신화 각성.
- **직업 강화**(생선): 직업별 5단계, 단계당 해당 직업 피해 +15%. 비용 60 / 100 / 160 / 240 / 340.
- **행운 캡슐**(🍀 2개): 캡슐 머신을 돌려 하나를 얻는다. 확률은 머신에 항상 표시.

| 결과 | 확률 |
|---|---|
| 생선 +40 | 28% |
| 희귀 유닛 | 38% |
| 영웅 유닛 | 24% |
| 전설 유닛 | 8% |
| 잭팟: 전설 유닛 + 🍀 3 | 2% |

  - 천장: 영웅 이상이 4번 연속 안 나오면 5번째는 영웅 이상 확정.
  - 연출 원칙: 캡슐 색이 먼저 결과 등급을 알려주고, 연출 중 낮아지지 않는다(가이드 §2.5).

### 3.7 장난감(유물)

막을 깰 때마다 3개 중 1개를 고른다(한 판에 5개). 무료 다시 뽑기 1회, 추가는 보상형 광고(판당 1회).

| 등급 | 예시 |
|---|---|
| 일반 | 털실 뭉치(전사·사수 공속 +12%) · 레이저 포인터(마법 피해 +15%) · 골판지 상자(소환 비용 −10%) · 방울 목걸이(처치 생선 +20%) · 낚싯대(사거리 +12%) · 스크래처(적 방어 −20%) |
| 희귀 | 캣타워(맨 윗줄 사거리 +25%·피해 +10%) · 꾹꾹이 쿠션(같은 직업이 인접하면 피해 +12%) · 고양이 터널(웨이브 시작 시 일반 유닛 1마리 무료) · 전기장판(둔화 효과 +30%, 둔화된 적에게 피해 +15%) · 돼지 저금통(웨이브 종료 시 보유 생선 20당 +1, 최대 +8) · 간식 스틱(합성 시 12% 확률로 두 등급 상승) |
| 영웅 | 네잎클로버 화분(행운 캡슐 영웅 이상 확률 +12%p) · 마따따비(치명 피해 +50%) · 자동 급식기(10초마다 생선 +6) · 유리구슬(광역·연쇄 범위 +25%) · 낮잠 담요(적 이동속도 −10%) · 쌍둥이 방울(소환 시 10% 확률로 한 마리 더) |
| 전설 | 복고양이 저금통(보유 생선 100당 전체 피해 +3%, 최대 +45%) · 아홉 목숨(적 한도 +15) · 별똥별(15초마다 무작위 적 5마리에게 큰 피해) · 황금 캣닢(시너지 필요 마릿수 −1) |

출시 유물 수: 일반 8 · 희귀 8 · 영웅 8 · 전설 6 = 30종. 일부는 업적으로 풀에 추가된다.

## 4. 유닛 (4직업 × 5등급 = 20종)

기준 화력(레벨 1, 초당 피해 예산): 일반 10 · 희귀 30 · 영웅 95 · 전설 300 · 신화 1,100. 한 등급 위가 약 3.1배이므로 2→1 합성은 항상 이득이면서 칸도 하나 비운다.

| 직업 | 일반 | 희귀 | 영웅 | 전설 | 신화(각성) |
|---|---|---|---|---|---|
| ⚔️ 전사 | **솜방망이** 빠른 냥펀치 | **검사냥** 3마리까지 베기 | **바이킹냥** 강타 + 방어 −30% 3초 | **사무라이냥** 긴 발도(관통) + 출혈 | **호랑이 장군** 광역 베기, 4타마다 포효(1초 기절 + 방어 붕괴) |
| 🏹 사수 | **새총냥** 단발 | **궁수냥** 속사, 치명 15% | **닌자냥** 수리검 3갈래 | **총잡이냥** 최대 체력 적 저격, 치명 ×3 | **별빛 사수** 관통·도탄, 처치 시 폭발 |
| 🔮 마법 | **눈덩이냥** 작은 광역 + 둔화 20% | **불꽃냥** 화염구 + 화상 | **번개냥** 연쇄 번개 4회 | **얼음 여왕** 눈보라(둔화 45% + 빙결) | **우주냥** 블랙홀(적을 뒤로 끌고 대폭발) |
| 🎁 재주 | **방울냥** 인접 공속 +10% | **요리사냥** 사거리 안 처치 시 생선 +1 | **악사냥** 인접 피해 +20% | **연금술사냥** 물약: 받는 피해 +30% + 독 | **복고양이** 전체 공속 +20%, 처치 시 5%로 🍀, 주기적 "대박" 동전 비 |

- 피해 유형: 전사·사수 = 물리, 마법 = 마법, 재주 = 마법(약함).
- 타깃 우선순위 기본값: 가장 오래 살아남은 적. 유닛 정보 카드에서 `먼저 / 강한 적 / 가까운 적`으로 변경 가능.
- 모든 유닛은 16종 기본 해금. 신화 각성 4종은 챕터 1~4 첫 클리어로 하나씩 해금된다(가챠 아님).

## 5. 적 (고양이가 싫어하는 것들)

한 가지 빌드로 전부 못 막게 **카운터가 있는 특성**을 준다. 특성은 다음 웨이브 예고에 아이콘으로 뜬다.

| 적 | 특성 | 약점 / 대응 |
|---|---|---|
| 오이 | 기본 | — |
| 먼지 뭉치 | 무리(많고 약함) | 광역 |
| 물방울 | 신속 | 둔화, 긴 사거리 |
| 로봇청소기 | 갑옷(물리 −50%), 느림 | 마법, 방어 깎기 |
| 귤 | 결계(마법 −50%) | 물리 |
| 풍선 | 분열(죽으면 작은 풍선 2개) | 광역, 여유 화력 |
| 알람시계 | 가속 오라(주변 적 이속 +30%) | 우선 처치(강한 적 타깃) |
| 약병 | 치유 오라 | 우선 처치, 폭딜 |
| 넥카라 | 보호막(처음 6회 피격 무효) | 속사 유닛 |
| 벼룩 | 매우 빠름, 회피 20% | 광역, 둔화 |
| 분무기(정예) | 주기적으로 유닛 1칸을 2초간 젖게 함(행동 불가) | 빠른 처치 |
| 폭죽(정예) | 죽을 때 주변 적 2초 가속 | 고립시켜 처치 |

| 보스 | 등장 | 패턴 |
|---|---|---|
| 대왕 오이(정예 보스) | 5·15·25웨이브 공용 | 체력이 줄수록 빨라짐 |
| 진공청소기 "흡입왕" | 거실 | 흡입: 3초간 전 유닛 공속 −30%, 자신은 보호막 |
| 믹서기 "윙윙이" | 주방 | 회전: 전 적 이속 +40% 4초 |
| 욕조 "목욕 대마왕" | 욕실 | 물방울 지속 소환, 2칸을 2초간 젖게 함 |
| 먹구름 "우르릉" | 마당 | 낙뢰: 2×2칸 2.5초 기절, 체력 50% 이하에서 주기 단축 |
| 주사기 "따끔 선생" | 동물병원 | 예방접종: 전 적 5초간 둔화 면역, 자가 회복 |

- 적 체력: `기준 체력 × 1.135^(웨이브−1) × 챕터 배수 × 난이도 배수`. 보스·정예는 별도 배수.
- 난이도는 유저를 약하게 하는 방식이 아니라 **적 구성과 특성 조합**으로 올린다.

## 7. 메타 시스템

### 7.1 재화

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 골드 | 전투 보상, 순찰, 미션, 상자 | 유닛 레벨업, 훈련소 |
| 보석 | 첫 클리어, 업적, 출석, 패스, 구매 | 상자, 일일 상점, 부활 |
| 유닛 카드 | 상자, 전투 보상, 패스 | 유닛 레벨업 |
| 패스 XP / 계정 XP | 전투, 미션 | 시즌 패스 단계 / 계정 레벨 보상 |

스태미나(행동력)는 두지 않는다 — 웹 포털 이용자는 "더 하고 싶을 때 막는" 장치에서 가장 많이 이탈한다.

### 7.2 유닛 레벨 (1~10)

- 레벨당 피해 +10%(최대 +90%). 4·7·10레벨에 유닛 고유 특전(예: 번개냥 연쇄 +1).
- 필요 카드 2 / 4 / 8 / 16 / 30 / 50 / 80 / 120 / 200, 골드 100 → 20,000.
- 챕터 5 보통은 평균 4레벨, 악몽은 평균 8레벨을 기준으로 맞춘다.

### 7.3 훈련소 (골드, 항목당 10단계)

시작 생선 +5 · 처치 생선 +2% · 전체 피해 +2% · 보스 제한시간 +1초 · 적 한도 +1 · 시작 🍀 +0.3(3·6·9단계에 +1).

### 7.4 상자 (카드 묶음, 확률 전부 공개)

| 상자 | 내용 | 얻는 곳 |
|---|---|---|
| 나무 | 카드 8장(일반·희귀 위주, 영웅 5%) + 골드 | 4시간마다 무료, 승리 보상 |
| 은 | 카드 24장(영웅 1장 이상 확정) + 골드 | 별 보상, 일일 미션, 150보석 |
| 금 | 카드 60장(전설 1장 이상 확정) + 보석 조금 | 챕터 첫 클리어, 패스, 500보석 |

- 금 상자 10개 안에 **아직 레벨이 가장 낮은 전설**의 카드가 반드시 포함된다(편중 방지 천장).
- 최대 레벨 유닛의 카드는 골드로 자동 환산된다(버려지는 보상 없음).
- 유닛 자체는 뽑기로 팔지 않는다. 상자는 **성장 속도**만 바꾼다.

### 7.5 반복 동기

| 장치 | 내용 |
|---|---|
| 출석 | 7일 주기 달력, 7일째 금 상자 |
| 일일 미션 5개 | 3판 플레이 · 합성 20회 · 보스 2마리 · 장난감 5개 · 일일 도전 → 포인트 100이면 은 상자 |
| 주간 미션 5개 | 누적형, 완료 시 금 상자 |
| 업적 | 약 30개, 보석과 장난감 해금 |
| 시즌 패스 | 30단계, 무료·프리미엄 2줄. 30일 주기 |
| 순찰(방치 보상) | 최고 챕터에 비례한 골드가 쌓인다(최대 8시간). 광고 시청 시 2배 |
| 계정 레벨 | 기능 해금(2배속·미션·상점·패스·일일 도전·무한)과 보석 보상 |

## 8. 수익화

### 8.1 채널별 믹스

| 구분 | 토스 · 모바일 스토어 | 웹 포털(CrazyGames·Poki 등) |
|---|---|---|
| 주 수익원 | IAP 60~80% + 광고 20~40% | 광고 100% |
| 보상형 광고 | DAU당 3~5회, 위치 7곳 | DAU당 2~4회(부활·2배·무료 상자 중심) |
| 전면 광고 | 기본 없음 | 포털 SDK가 빈도 관리, 판과 판 사이에만 |
| IAP | 아래 8.3 전부 | 없음(상점의 결제 상품을 숨김) |
| 광고 제거 | 영구 패스로 판매 | 해당 없음 |

근거: 한국 등 성숙 시장은 매출의 77~90%가 IAP, 운빨존많겜은 광고 비중 약 7%(수익화 분석 §1.2). 포털은 SDK 광고가 의무이고 IAP가 사실상 불가(§B-7).

### 8.2 보상형 광고 (전부 선택형, 완료 이벤트에서만 지급)

| 위치 | 보상 | 제한 |
|---|---|---|
| 부활 | 패배 직전 상태에서 적 절반 제거 후 계속 | 판당 1회 |
| 결과 화면 | 전투 보상 2배 | 판당 1회 |
| 장난감 다시 뽑기 | 3택 재추첨 | 판당 1회 |
| 무료 나무 상자 | 대기 시간 건너뛰기 | 하루 4회 |
| 순찰 2배 | 순찰 골드 2배 | 하루 3회 |
| 일일 상점 새로고침 | 상품 재추첨 | 하루 2회 |
| 출발 보너스 | 생선 +60 또는 🍀 +2로 시작 | 판당 1회 |

- 홈 화면과 결과 화면에 **보상 내용을 먼저 보여 주는** 버튼으로 노출하고, 무료 상자는 준비되면 배지로 알린다(상점 안에 숨기지 않는다 — 수익화 분석 §B-1.1).
- 첫 판에는 광고 제안이 없다. 두 번째 판부터 맥락에 맞게 제안한다.
- 전면 광고는 **웹 포털 빌드에서만**, 판과 판 사이에만, 최소 120초 간격, 패배 직후·첫 세션 제외.
- 광고 중에는 전투 정지 + 전체 음소거, 실패하면 보상 없이 원래 흐름으로 복귀.

### 8.3 IAP (힘이 아니라 시간·편의)

| 상품 | 가격(원, VAT 포함) | 내용 |
|---|---|---|
| 첫 구매 팩(1회) | 1,100 | 보석 120 + 은 상자 1 |
| 스타터 팩(1회) | 3,300 | 보석 300 + 금 상자 1 + 골드 5,000 |
| 성장 패키지(1회) | 6,600 | 보석 700 + 금 상자 2 + 골드 15,000 |
| 프리미엄 집사 패스(영구) | 9,900 | 광고 없이 모든 광고 보상 즉시 수령, 전면 광고 제거, 순찰 한도 8 → 12시간 |
| 시즌 패스(30일) | 9,900 | 프리미엄 보상 줄(보석·상자·골드) |
| 월간 보석 카드 | 5,900 | 즉시 200 + 30일간 매일 30 |
| 저금통 | 2,200 → 5,500 → 11,000 | 플레이로 보석이 쌓이고(판당 적립), 가득 차면 표시된 가격으로 깬다 |
| 보석 | 1,500 / 5,900 / 12,000 / 33,000 / 55,000 | 80 / 350 / 800 / 2,500 / 4,500 |
| 성장 펀드 | 19,000 | 챕터 클리어마다 보석 지급(총 4,000) |

- 가격대 근거: 첫 결제는 ₩1,100~3,300이 전환 구간, 선행작 앵커 ₩6,600 / 12,000 / 17,000 / 33,000 (수익화 분석 §B-4).
- 판매하지 않는 것: 유닛, 인런 확률, 배속, 장난감. "실패 직후 압박형 구제 팩"은 넣지 않는다.
- 확률형 상품(상자)은 구매 화면에서 `확률 보기`로 항목별 확률과 천장을 공개한다. 확률표 하나가 **추첨 코드와 확률 화면의 공통 원본**이다(게임산업법 2025-08-01 시행 개정, Apple 3.1.1, Google Play 결제 정책 7항).
- 홈 진입 시 판촉 팝업은 하루 1개 이하, 첫 세션에는 0개. 판촉에는 레드닷을 쓰지 않는다.
- 결제 지급은 멱등하게 처리하고, 시작 시 미완료 주문을 복구한다.

### 8.4 결제·광고 구현 범위

본 저장소에는 **플랫폼 추상화 계층과 개발용(Mock) 제공자**(가짜 광고 5초, 테스트 결제 확인창)가 들어간다. 채널 어댑터(CrazyGames / Poki / GameDistribution / YouTube Playables / 토스 / Capacitor)는 조사한 SDK 표면에 맞춰 작성하되, 실계정·SDK 키가 있어야 하는 실연동 검증은 출시 준비 단계의 작업으로 남긴다(§18).

## 9. 첫 3분 (FTUE)

| 시각 | 사건 |
|---|---|
| 0~3초 | "탭해서 시작"(오디오 잠금 해제) → 바로 전장. 메뉴·로그인·약관 없음 |
| 3~8초 | 소환 버튼만 빛난다. 손가락 포인터, 문구 한 줄 |
| 8~20초 | 무료 소환 3회(같은 일반 유닛 2마리가 나오게 연출) |
| 20~35초 | "같은 고양이끼리 합쳐 보세요" → 첫 합성 연출 |
| 35~60초 | 2~4웨이브, 직업 칩이 3마리에서 빛나며 시너지 한 줄 안내 |
| 60~90초 | 5웨이브 정예 처치 → 첫 장난감 3택(추천 표시) |
| 90~170초 | 10웨이브 보스 → 승리 → 첫 나무 상자 → 홈 |

- 강제 구간은 소환·합성·3택 세 단계뿐이고, 나머지는 처음 등장할 때 말풍선 한 번.
- 첫 판의 소환은 "초반 행운 보너스"로 보정하며, 그 사실을 화면에 표기한다.

## 10. 화면 구성

- **홈**(하단 탭 5개: 상점 · 고양이 · **전투** · 미션 · 패스): 챕터 카드, 큰 `출동` 버튼, 순찰 상자, 일일 도전, 출석.
- **전투**: 상단 HUD(막-웨이브, 타이머, 적 수 게이지, 일시정지·배속, 장난감 줄, 다음 웨이브 예고) / 전장 / 하단(직업 칩 4개, 🐟·🍀, `강화` · **소환**(300×140) · `캡슐`).
- **고양이**: 20종 카드 그리드 → 상세(능력치, 레벨업, 각성 조건).
- **상점**: 상자, 일일 상점, 보석, 패스·팩.
- **미션**: 일일 / 주간 / 업적.
- **패스**: 30단계 보상 줄.
- **팝업**: 장난감 3택, 골라 뽑기, 유닛 정보, 확률 보기, 행운 캡슐, 일시정지, 결과(승리/패배), 보상 수령, 설정, 출석, 순찰.
- 터치 영역 최소 96×96, 본문 28 이상, 등급은 색 + 테두리 모양 + 핍 개수로 중복 표기(가이드 §3).

## 11. 연출과 사운드

- **등급 사다리**(가이드 §2.0): 일반(T0) 먼지 팝 250ms → 희귀 파란 링 → 영웅 보라 빛기둥 → 전설 금빛 기둥 + 충격파 + 히트스톱 50ms → **신화 각성 컷인 1.5~1.9초**(두 번째부터 0.8초 단축본).
- **합성**: 끌려가 부딪힘 120ms → 팝 260ms(back-out) → 등급색 링. 연속 합성은 음정이 반음씩 오른다.
- **전투**: 발사 스쿼시, 피격 흰 번쩍임 50ms, 피해 숫자(치명은 크고 노랗게), 처치 시 연기 + 생선이 HUD로 날아감.
- **보스**: 경고 띠 + 사이렌 → 등장 착지 흔들림 → 체력 바 잔상 → 사망 시 슬로모 + 연쇄 폭발 + 전리품 비.
- **위험 상태**: 가장자리 붉은 비네트(2Hz 이하), 심장박동, 음악 저역 필터.
- **사운드**: 전부 WebAudio 절차 합성. 효과음 60종, 음악 3곡(홈 96BPM · 전투 128BPM 4단 강도 · 보스 142BPM), 스팅어 6종. 전투 강도는 적 수와 웨이브에 따라 층이 쌓인다.
- **접근성**: 화면 흔들림·번쩍임·모션 감소·햅틱 토글, 풀스크린 번쩍임은 초당 2회·알파 0.45 이하.

## 12. 아트 방향

- **유닛**: 2등신 치비 고양이, 굵은 외곽선 + **흰 스티커 테두리**(복잡한 배경 위에서도 80px 크기로 읽힌다 — 시안 비교로 확정). 직업은 소품(검·활·지팡이·방울), 개체는 털 무늬로 구분.
- **적**: 같은 화풍이되 흰 테두리 없이 굵은 어두운 외곽선 → 아군/적이 즉시 구분된다.
- **전장**: 위에서 내려다본 방(거실·주방·욕실·마당·동물병원). 러그는 무늬를 약하게 하고 칸 표시는 코드로 그린다.
- **UI**: 코드로 그린 둥근 입체 버튼(보라 바탕 + 노랑 강조), 아이콘은 벡터.
- **제작**: Codex(gpt-6-astra) 이미지 생성 → `tools/process_art.py`로 트림·리사이즈·WebP.

## 13. 밸런스 원칙과 검증

- 전투 로직은 화면과 분리된 **결정적 시뮬레이션**(시드 기반)이다 → 같은 시드는 같은 결과.
- `npm run sim`: 정책이 다른 봇(무작정 소환 / 합성 우선 / 시너지 지향)으로 챕터별 1,000판을 돌려 승률·평균 도달 웨이브·적 수 곡선을 뽑는다.
- 목표: 메타 성장 0에서 챕터 1 보통 승률 — 무작정 봇 35% / 시너지 봇 85%. 챕터가 오를 때마다 권장 유닛 레벨 +1.
- RNG 검증: 소환·캡슐·상자의 표기 확률과 실제 분포를 카이제곱으로 자동 검정(확률 구현 오류는 곧 평판·법 리스크).

## 14. 기술 설계

| 영역 | 결정 |
|---|---|
| 스택 | TypeScript(strict) + PixiJS 8(WebGL) + Vite. 외부 CDN 호출 없음, 상대 경로 빌드 |
| 구조 | `core`(앱 셸·트윈·씬·세이브·다국어) / `game`(순수 로직·데이터) / `view`(전투 렌더) / `fx` / `ui` / `audio` / `meta`(프로필·경제) / `platform`(광고·결제·분석 어댑터) / `scenes` |
| 전투 | 60Hz 고정 스텝 시뮬레이션 + 이벤트 스트림. 화면은 이벤트를 받아 연출만 한다 |
| 세이브 | 버전·마이그레이션이 있는 JSON, 저장소 백엔드 교체 가능(localStorage → 포털 저장 API) |
| 성능 예산 | 파티클 700, 피해 숫자 40, 드로콜 60 이하, 해상도 배율 최대 2. 중급 폰 60fps |
| 용량 예산 | 한글 폰트는 사용 글자만 서브셋, 이미지는 WebP |
| 다국어 | 한국어·영어, 문자열 키 관리 |
| 플랫폼 | `PlatformAdapter`(수명주기·광고·저장·결제·식별·순위표) + `AdService`(정지/음소거 보장, 보상 단일 경로, 위치별 쿨다운·일일 상한) + `IapService`(멱등 지급, 미완료 주문 복구) + `Analytics`. 어댑터: dev(Mock) · CrazyGames · Poki · GameDistribution · YouTube Playables · 토스 · Capacitor. 빌드 플래그 `VITE_PLATFORM`으로 해당 어댑터만 포함 |
| 채널 공통 제약 | 외부 요청 0, `eval` 없음, 상대 경로, 파일명 `[A-Za-z0-9_.-]`, 파일 1,000개 이하, 초기 다운로드 15MiB 이하(목표 8MB), JS 힙 256MB 목표, 첫 화면 10초 이내, 보상은 광고 완료 이벤트에서만, YouTube 빌드는 Page Visibility 대신 SDK의 일시정지 신호 사용 |
