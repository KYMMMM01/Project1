# 전투 규칙 명세 (구현 기준)

> [기획서](기획서_GDD.md) §3~§6의 규칙을 **추측 없이 구현할 수 있는 수준**으로 적은 문서다.
> 계약: `src/game/api.ts`(타입·명령·이벤트), `src/game/geometry.ts`(좌표). 수치의 원본은 `src/game/data/*.ts`이며 여기 적힌 값은 초기값이다.
> 좌표는 전장 공간 px, 시간은 초.

## 1. 시간과 진행

- 고정 스텝 `H = 1/60`. `step(dt)`는 누적기에 더한 뒤 `H`씩 소비한다. 한 번의 호출에서 최대 10틱(밀린 시간은 버린다).
- 단계(`phase`): `prep` → `wave` ⇄ `choice` → `won` | `lost`.
  - `prep`: 3초(튜토리얼은 첫 소환 전까지 대기). 소환·이동·합성 가능.
  - `choice`: `pending`이 있는 동안 **틱이 돌지 않는다**(웨이브 타이머·보스 제한시간·쿨다운·상태이상 전부 정지). 명령은 해당 선택 명령만 받는다.
  - `won` / `lost`: `step`은 아무 일도 하지 않는다. `lost`에서 `revive()`만 가능.
- 배속과 일시정지는 화면 쪽 책임이다(`dt`를 곱하거나 `step`을 부르지 않는다).
- 같은 `BattleInit`(시드 포함)과 같은 명령 순서·틱 위치는 항상 같은 결과를 낸다. 난수는 `core/rng`의 `Rng` 인스턴스만 쓴다. 용도별로 스트림을 나눈다: 소환, 캡슐, 장난감, 웨이브 구성, 전투(치명·회피·타깃 동률).

## 2. 웨이브

| 종류 | 웨이브 | 길이 / 제한 | 종료 조건 |
|---|---|---|---|
| 일반 | 막의 1~4번째 | 16초(1~3웨이브는 18초) | 타이머 만료. 남은 적은 그대로 두고 다음 웨이브 시작 |
| 정예 | 5·15·25 | 제한 45초 | 정예 보스 처치 → 1.5초 뒤 막 클리어. 제한시간에 살아 있으면 패배(`boss_timeout`) |
| 보스 | 10·20·30 | 제한 60초 | 보스 처치 → 1.5초 뒤 막 클리어(30웨이브면 승리) |

- 스폰: 웨이브 시작 0.6초 뒤부터 앞 10초에 걸쳐 그룹별 간격으로 나온다. 정예·보스는 1.0초에 등장하고 호위는 계속 나온다.
- 스폰 위치는 경로 거리 0(왼쪽 위). 적의 위치는 `pathPoint(travelled)`.
- 막 클리어: `actClear` 이벤트(🍀 +2, 생선 `30 + 10×막`) → 장난감 3택(`pending.kind = 'relic'`) → 선택 후 1초 뒤 다음 웨이브.
- 튜토리얼: 10웨이브(2막), 5웨이브 뒤 장난감 3택, 10웨이브 보스는 약화한 `boss_cucumber`.
- 무한: 30웨이브 이후에도 같은 막 구조로 계속. 체력 성장률이 웨이브당 1.135 → 1.16으로 오른다. 장난감은 풀이 남는 동안 제공.
- 일일 도전: 20웨이브(4막), 보스는 10·20.

## 3. 패배와 부활

- 매 틱 `enemyCount > enemyCap`이면 `lost`(`overrun`). 기본 한도 60.
- 위험 단계(`danger` 이벤트, 바뀔 때만): 적 수 ≥ 한도×2/3 → 1, ≥ 한도×5/6 → 2.
- `revive()`(판당 1회): 보스·정예가 아닌 적을 `travelled`가 큰 순서로 제거해 적 수를 한도×40% 이하로 만들고, 보스 제한시간이 있으면 +20초, `phase = 'wave'`.

## 4. 소환

- 비용 `min(상한, 12 + 4n)`. `n`은 이번 판에 **버튼으로 값을 치른** 소환 횟수(무료 소환·캡슐·장난감은 세지 않는다). 상한 80. `cardboard_box`는 비용 ×0.9(올림), `sardine_crate`는 상한 −15.
- 빈 칸이 없으면 `board_full`(비용을 받지 않는다).
- 등급: 행운 단계 `L(0~5)`의 확률표에서 뽑는다.

| 단계 | 일반 | 희귀 | 영웅 | 전설 |
|---|---|---|---|---|
| 0 | 70 | 25 | 5 | 0 |
| 1 | 64 | 28 | 7.4 | 0.6 |
| 2 | 58 | 31 | 9.8 | 1.2 |
| 3 | 52 | 34 | 12.2 | 1.8 |
| 4 | 46 | 37 | 14.6 | 2.4 |
| 5 | 40 | 40 | 17 | 3 |

  - 행운 강화 비용(생선): 80 / 130 / 190 / 260 / 340.
  - 소프트 천장: 영웅 이상 없이 `epicDry ≥ 12`이면 영웅 확률에 `+3%p × (epicDry − 11)`을 더하고 같은 양을 일반에서 뺀다(일반이 0이 되면 희귀에서). 영웅 이상이 나오면 0으로.
  - 하드 천장: 일반이 연속 7번이면 다음 뽑기는 일반을 제외하고 나머지를 정규화해 뽑는다.
  - `summonOdds()`는 이 보정을 **모두 반영한 현재 확률**을 돌려준다(화면에 보이는 표 = 실제 추첨 표).
- 직업: 허용 직업 중 균등. 유닛 = (직업, 등급)의 유닛.
- 위치: 빈 칸 중 균등 무작위.
- 골라 뽑기: 버튼 소환 6번째마다 비용을 받은 뒤 후보 3개를 만든다(각자 등급을 굴리되 일반이면 희귀로, 서로 다른 유닛이 되도록 최대 8번 다시 굴림). `pending.kind = 'summon'`. `pickSummon(i)`로 배치.
- `twin_bells`: 버튼 소환 성공 시 10%로 같은 유닛을 빈 칸에 하나 더(`source: 'twin'`). 빈 칸이 없으면 생략.

## 5. 보드 조작

`drop(from, to)`의 결과(`dropAction`과 일치):

| `to`의 상태 | 결과 |
|---|---|
| 같은 칸 / 범위 밖 | `none` |
| 빈 칸 | `move` |
| 같은 유닛(일반~영웅) | `merge`: 둘을 지우고 `to`에 한 등급 위 무작위 직업의 유닛 |
| 같은 전설 | `merge`: 그 직업의 신화. 해금되지 않았으면 `swap`으로 처리 |
| 그 밖 | `swap` |

- 합성 결과 유닛의 공격 게이지는 0.5에서 시작, 타깃 방식은 `first`.
- `snack_stick`: 합성 시 12%로 두 등급 상승(최대 전설) → `merge.jumped = true`.
- 이동·교환은 공격 게이지를 유지한다. `disabled` 상태의 유닛도 옮길 수 있고 남은 시간은 유닛을 따라간다.
- 판매 환급: 일반 6 / 희귀 18 / 영웅 55 / 전설 170 / 신화 500 생선, 영웅·전설 🍀 +1, 신화 🍀 +3.
- 각성 `awaken(cell)`: 전설 유닛 + 그 직업 시너지 2단계 이상 + 🍀 3 + 해당 신화 해금. 실패 사유는 `canAwaken`이 같은 순서로 판정(`empty_cell` → `not_legendary` → `mythic_locked` → `synergy_too_low` → `not_enough_clover`).

## 6. 직업 시너지

- 마릿수 = 보드 위 그 직업 유닛 수(등급 무관). 필요 마릿수 `[3, 5, 7]`(`golden_catnip`: `[2, 4, 6]`).
- 효과(해당 단계의 값으로 대체, 누적 아님):

| 직업 | 1단계 | 2단계 | 3단계 | 적용 대상 |
|---|---|---|---|---|
| warrior | 피해 +25% | 피해 +60%, 방어 30% 무시 | 피해 +120%, 방어 60% 무시 | 전사 |
| ranger | 치명 +12%p | 치명 +25%p, 치명 피해 +0.5 | 치명 +40%p, 치명 피해 +1.2 | 사수 |
| mage | 피해 +25% | 피해 +60%, 상태이상 지속 ×1.4 | 피해 +120%, 지속 ×1.8 | 마법 |
| trickster | 공속 +8% | 공속 +16%, 웨이브 보상 ×1.2 | 공속 +28%, 웨이브 보상 ×1.5 | 전 아군 |

- 단계가 바뀌면 `synergy` 이벤트.

## 7. 유닛 능력치

보드·장난감·강화가 바뀔 때만 다시 계산한다.

```
피해   = 기본 × (1 + 0.10 × (레벨 − 1)) × (1 + Σ 피해 보너스) × 복고양이 저금통 배수
간격   = 기본 ÷ (1 + Σ 공속 보너스)      (보스 '흡입' 중에는 추가로 ×1/0.7)
사거리 = 기본 × (1 + Σ 사거리 보너스)
치명   = min(1, 기본 + Σ),  치명 배수 = 기본 + Σ
```

- 피해 보너스(전부 합산): 직업 강화(단계당 +15%), 시너지, 훈련(단계당 +2%), 장난감, 인접 버프.
- 인접 버프는 상하좌우 4칸. **같은 종류는 중첩하지 않고 가장 큰 값 하나**만 적용(방울냥 공속 +10%, 악사냥 피해 +20%).
- 직업 강화: 직업별 5단계, 비용 60 / 100 / 160 / 240 / 340.

## 8. 타깃과 명중

- 후보: `거리(칸 중심, 적 위치) ≤ 사거리`인 살아 있는 적.
- `first`: `travelled` 최대. `strong`: 현재 체력 최대(동률은 `first`). `near`: 거리 최소. 동률이 남으면 `uid`가 작은 쪽.
- 후보가 없으면 게이지를 1로 유지하다가 후보가 생긴 틱에 즉시 공격.
- 투사체는 유도. 속도는 유닛별(대개 900px/s). 대상이 먼저 죽으면 마지막 위치로 날아가 80px 안의 가장 가까운 적을 맞히고, 없으면 사라진다(`projectileEnd.hit = false`).
- 치명·회피는 명중 시점에 굴린다.

## 9. 피해와 상태이상

```
최종 피해 = 피해 × (치명 ? 치명 배수 : 1) × (1 − 방어율) × (1 + 취약)
방어율(물리) = armor × (1 − 방어 붕괴) × (1 − 전사 방어 무시) × (scratcher ? 0.8 : 1)
방어율(마법) = ward  × (scratcher ? 0.8 : 1)
```

- 보호막(`shield > 0`): 직접 타격 1회를 완전히 막고 1 감소. 지속 피해 틱은 막지 않는다.
- 회피(`evasive`): 단일 대상 타격의 20%를 피한다(광역·지대·연쇄는 피하지 못한다).
- 상태이상(적 하나당 종류별 1개):

| 종류 | 규칙 |
|---|---|
| slow | 가장 강한 값이 이긴다. 지속은 더 긴 쪽. 보스·정예는 효과 절반. `heating_pad`: 둔화율 ×1.3(상한 80%) |
| stun / freeze | 지속은 더 긴 쪽. 보스는 면역, 정예는 지속 절반 |
| burn / poison / bleed | 초당 피해는 더 큰 쪽, 지속은 갱신. 0.5초마다 틱. 피해 유형: burn·poison = 마법, bleed = 물리 |
| armor_break / vulnerable | 가장 강한 값, 지속은 더 긴 쪽 |

- 마법 시너지의 지속 배수는 slow·burn·poison·freeze·vulnerable에 적용.
- 이동: `속도 × (1 − 둔화) × (1 + 가속)`, 기절·빙결 중에는 0. `nap_blanket`: 전 적 속도 ×0.9.

| boss_bath | 80 | 38 | `splash`: 5초마다 `drop` 3마리 소환, 10초마다 유닛 2칸을 2초간 행동 불가 |
| boss_cloud | 85 | 40 | `lightning`: 9초마다(체력 50% 이하에서 6초) 무작위 2×2칸 2.5초 행동 불가 |
| boss_needle | 95 | 40 | `vaccinate`: 11초마다 5초간 모든 적 둔화 면역, 자신은 초당 최대 체력의 1% 회복 |

- 보스 처치: 생선 60, 🍀 +3. 정예 보스(`boss_cucumber`가 5·15·25에 나올 때)·정예: 🍀 +1.
- 챕터 배수: 1.0 / 1.6 / 2.5 / 3.9 / 6.0. 난이도 배수: 1.0 / 2.2 / 4.5(어려움·악몽은 특성 적이 더 일찍, 더 많이 섞인다).
- 웨이브 구성은 `data/waves.ts`에 챕터별 30웨이브를 직접 적는다. 원칙: 새 특성은 막마다 하나씩 소개, 같은 웨이브에 물리 카운터와 마법 카운터를 함께 요구하지 않는다(보스 웨이브 제외), 무리 웨이브 다음은 숨 고르기.

## 11. 경제

- 시작: 생선 100(+훈련, +출발 보너스), 🍀 0(+훈련, +출발 보너스).
- 처치 생선은 표의 값 × (1 + `bell_collar` 0.2 + 훈련). 소수는 누적해 정수가 될 때 지급.
- 웨이브 종료: `18 + 2 × 웨이브`, 재주 시너지 배수, `tuna_cans` +12, `piggy_bank` 보유 생선 20당 +1(최대 +8).
- `auto_feeder`: 10초마다 +6. `sardine_crate`: 획득 즉시 +150.
- 행운 캡슐: 🍀 2. 결과표는 기획서 §3.6. `clover_pot`은 생선 28% → 16%, 영웅 24% → 36%. 4번 연속 영웅 미만이면 5번째는 생선·희귀를 제외하고 정규화. 유닛 결과인데 빈 칸이 없으면 그 등급의 판매가(생선)로 지급.
- `maneki_bank`: 전체 피해 배수 `1 + min(0.45, 0.03 × floor(생선 / 100))`. 생선이 100 단위 경계를 넘을 때만 다시 계산.

## 12. 장난감

- 제안: 보유하지 않은 것 중 서로 다른 3개. 등급 가중치(일반/희귀/영웅/전설): 1막 60/30/9/1, 막마다 일반 −8, 희귀 +2, 영웅 +4, 전설 +2.
- 다시 뽑기: 무료 1회/판, 유료(광고) 1회/판.
- 효과는 기획서 §3.7과 `data/relics.ts`. 특수 처리:
  - `cat_tunnel`: 웨이브 시작 시 빈 칸이 있으면 일반 등급 무작위 유닛 1마리(`source: 'relic'`).
  - `shooting_star`: 15초마다 무작위 적 5마리에게 `기준체력(현재 웨이브) × 0.6`의 마법 피해.
  - `nine_lives`: 한도 +15. `hourglass`: 보스·정예 제한 +15초, 스폰 간격 ×1.1.
  - `kneading_cushion`: 상하좌우에 같은 직업이 하나라도 있으면 그 유닛 피해 +12%.
  - `cat_tower`: 맨 윗줄 유닛 사거리 +25%, 피해 +10%. `window_perch`: 바깥 줄 칸의 유닛 공속 +15%.

## 14. 검증

- 단위 테스트: 경로·칸 기하, 확률표 합 = 1, 천장 동작, 합성·각성 판정, 피해 공식, 상태이상 규칙, 시너지 계산, 명령 실패 사유.
- 분포 검정: 소환·캡슐 10만 회 표본의 등급 분포가 `summonOdds()` / `capsuleOdds()`와 카이제곱 p > 0.001.
- 불변식(무작위 명령 퍼징): 생선·🍀 ≥ 0, 유닛 ≤ 20, `enemies.length = enemyCount`, NaN 없음, 같은 시드·같은 명령 = 같은 결과.
- 밸런스 봇(`npm run sim`): 무작정 소환 / 합성 우선 / 시너지 지향 정책으로 챕터·난이도·유닛 레벨별 승률과 도달 웨이브 분포를 출력. 목표는 기획서 §13.
