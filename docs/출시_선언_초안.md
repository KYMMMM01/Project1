### 데이터 유형

"공유"는 다른 회사가 자기 목적으로 쓰는 것이다. 우리를 대신해 처리하는 서비스 제공자(Firebase, RevenueCat)로 보내는 것은 공유가 아니다. AdMob 은 구글 문서가 직접 "수집하고 공유한다"고 적었으므로 공유로 둔다.

| 범주, 유형 | 수집 | 공유 | 선택 여부 | 목적 | 어디서 |
|---|---|---|---|---|---|
| 개인 정보, 이름 | 예 | 아니요 | 선택(로그인한 경우만) | 앱 기능, 계정 관리 | 게임 닉네임. 구글 정의의 이름에 닉네임이 들어간다. 랭킹에서 다른 사람에게 보인다 |
| 개인 정보, 이메일 주소 | 예 | 아니요 | 선택 | 계정 관리, 사기 방지와 보안 | Firebase Auth 가 구글 로그인 응답에서 받는다 |
| 개인 정보, 사용자 ID | 예 | 아니요 | 선택 | 앱 기능, 계정 관리 | Firebase 사용자 ID, 구글 계정 ID, Play 게임즈 플레이어 ID. RevenueCat 익명 ID 도 여기 든다고 본다(RevenueCat 문서는 이 항목을 말하지 않음) |
| 금융 정보, 구매 내역 | 예 | 아니요 | 필수 | 앱 기능, 분석 | RevenueCat 문서가 이 하나를 필수로 꼽았다. 일시적 처리 아님 |
| 위치, 대략적인 위치 | 예 | 예 | 필수 | 광고 또는 마케팅, 분석, 사기 방지와 보안 | AdMob 이 IP 주소로 대략 위치를 추정한다. Firebase Auth 도 IP 를 부정 이용 방지에 쓴다 |
| 앱 활동, 앱 상호작용 | 예 | 예 | 필수 | 광고 또는 마케팅, 분석, 사기 방지와 보안 | AdMob(앱 실행, 탭, 동영상 시청) |
| 앱 활동, 기타 작업 | 예 | 아니요 | 선택 | 앱 기능 | 게임 진행(Firestore 클라우드 저장), 랭킹 기록, Play 게임즈 업적. 구글 설명의 "게임 플레이" 가 이 항목이다 |
| 앱 정보 및 성능, 진단 | 예 | 예 | 필수 | 광고 또는 마케팅, 분석, 사기 방지와 보안 | AdMob(실행 시간, 멈춤 비율, 전력 사용) |
| 기기 또는 기타 ID | 예 | 예 | 필수 | 광고 또는 마케팅, 분석, 사기 방지와 보안 | AdMob(광고 ID, 앱 세트 ID) |

넣지 않는 것
- 비정상 종료 로그: AdMob 문서에 없고 RevenueCat 은 수집하지 않는다고 했다. Crashlytics 도 없다.
- 사진, 연락처, 정밀 위치, 메시지, 건강, 파일: 쓰지 않는다.
- 게스트로만 하면 이메일, 이름, 기타 작업은 서버로 가지 않지만, 양식은 앱 전체 기준이라 위처럼 "선택"으로 둔다.

[확인 필요]
- Firebase Cloud Functions 클라이언트가 FCM 토큰을 모은다고 적혀 있다. FCM 토큰은 기기 또는 기타 ID 로 볼 수 있는데, 이 행은 AdMob 때문에 이미 "예"라서 추가 행은 필요 없다. 목적에 앱 기능을 더할지는 고르면 된다(권함: 더함).
- Play 게임즈는 구글 Play 자체 서비스다. 처리방침에 적은 대로 플레이어 ID 와 업적을 위 표에 이미 넣었으니 따로 늘릴 것은 없다.

## 2. 콘텐츠 등급(IARC 설문)

연락 이메일은 처리방침과 같은 공개 문의 메일. 카테고리는 **게임**.

| 질문 | 권하는 답 | 이유 |
|---|---|---|
| 폭력 | 예 | 고양이가 오이, 먼지 뭉치, 로봇청소기 같은 물건을 공격해 없앤다 |
| 폭력이 사실적인 사람이나 동물을 향하나요 | 아니요 | 사람과 동물 적이 없다. 만화풍 판타지 폭력 |
| 피, 잔혹함 | 아니요 | 피 표현 없음 |
| 공포 | 아니요 | |
| 성적 내용, 노출 | 아니요 | |
| 욕설, 비속어 | 아니요 | 게임 글에 없음. 닉네임은 서버가 쓸 수 없는 말을 거른다 |
| 약물, 술, 담배 | 아니요 | "약병" 적은 치료 오라를 가진 물건이고 약물 사용 묘사가 아니다 |
| 저속한 유머 | 아니요 | |
| 도박, 모의 도박 | 아니요 | 카지노 같은 놀이가 없다 |
| 무작위 아이템 구매(뽑기) | 예 | 보석으로 상자를 열 수 있고 보석은 돈으로도 산다. 확률은 게임 안에 공개 |

| 사용자 위치를 다른 사용자와 공유하나요 | 아니요 | |
| 제한 없는 인터넷 접근 | 아니요 | 앱 안 브라우저 없음. 처리방침 링크는 바깥 브라우저로 연다 |

예상 결과: 한국(GRAC) 전체이용가 또는 12세, 나머지 지역은 만화 폭력과 뽑기 표시가 붙은 낮은 등급. **[확인 필요]** 실제 등급은 설문을 낸 뒤 바로 나온다.

## 3. 앱 액세스(로그인 세부정보)

확정: **모든 기능을 특별한 액세스 권한 없이 사용할 수 있음**.

이유: 게임 전체가 로그인 없이 된다. 클라우드 저장과 랭킹 등록만 구글 로그인이 필요한데, 아무 구글 계정으로 되므로 심사자에게 줄 전용 아이디와 비밀번호가 없다.

**[결정]** 더 조심하려면 "일부 기능 제한" 을 고르고 아래 안내만 넣는다(아이디와 비밀번호 칸은 비움).

> 모든 게임 기능은 로그인 없이 쓸 수 있습니다. 설정, 계정에서 구글 로그인을 하면 클라우드 저장과 랭킹이 열리며, 어떤 구글 계정이든 됩니다. 로그인 전에 만 14세 이상인지 묻습니다.
