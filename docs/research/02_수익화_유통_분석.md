## 0. 표기 규칙과 데이터 신뢰도 (먼저 읽기)

| 표기 | 의미 |
|---|---|
| `VERIFIED[n]` | Sources 섹션의 번호 n URL에서 직접 확인한 수치/문구 (공식 문서, 데이터 벤더 리포트, 업계 매체 포함) |
| `VERIFIED[n·2차]` | 해당 URL이 그렇게 말하고 있으나 벤더 블로그/재인용/검색 스니펫 기반이거나, 페이지 직접 열람이 실패하여 검색 결과 요약만 확인한 것. 방향성 참고용 |
| `ESTIMATE` | 검증된 입력값으로 계산했거나 분석가가 판단한 추정. 실측 아님 |

- **벤더 간 추정치는 서로 다릅니다.** (Sensor Tower, AppMagic, 점점데이터 등은 gross/net, 집계 기간, 국가 범위가 다름) 같은 게임의 숫자가 출처마다 다르면 둘 다 병기했습니다.
- 대부분의 공개 벤치마크는 "중·대형 스튜디오 + 유료 UA(유저 획득)" 게임에서 나온 값입니다. **1인 개발의 무(無)마케팅 유기적 유입 환경에 그대로 적용되지 않습니다.**

```ts
type AdKind = 'interstitial' | 'rewarded';
interface AdResult { shown: boolean; rewarded?: boolean; error?: string }

interface PlatformAdapter {
  readonly id: 'dev' | 'crazygames' | 'poki' | 'gd' | 'yt' | 'toss' | 'capacitor' | 'telegram' | 'discord';
  init(): Promise<void>;

  lifecycle: {
    loadingStart?(): void;            // CrazyGames loadingStart
    loadingFinished?(): void;         // Poki gameLoadingFinished / CrazyGames loadingStop
    firstFrameReady?(): void;         // YT firstFrameReady
    gameReady?(): void;               // YT gameReady
    gameplayStart(): void;            // Poki/CrazyGames gameplayStart
    gameplayStop(): void;             // Poki/CrazyGames gameplayStop
    onPause(cb: () => void): void;    // YT onPause; others: visibility/audio focus
    onResume(cb: () => void): void;
  };

  ads: {
    isAvailable(kind: AdKind, placement: string): boolean;
    preload?(kind: AdKind, placement: string): void;     // Toss load*, AdMob load*
    show(kind: AdKind, placement: string): Promise<AdResult>;
    // Wrapper (outside adapter) must: pause loop + mute BEFORE show, restore AFTER,
    // grant reward ONLY when result.rewarded === true, enforce per-placement caps.
  };

  storage: {
    maxBytes: number;                 // YT 3MiB, Telegram per-key 4096 chars, etc.
    get(key: string): Promise<string | null>;
    set(key: string, value: string): Promise<void>;
    remove(key: string): Promise<void>;
  };

  audio?: { isSystemMuted(): boolean; onSystemMuteChange(cb: (muted: boolean) => void): void };
  iap?: {
    products(): Promise<Array<{ id: string; priceText: string }>>;
    purchase(id: string): Promise<{ ok: boolean }>;   // grant must be idempotent
    recoverPending(): Promise<void>;                  // Toss getPendingOrders etc.
  };
  identity?: { userKey(): Promise<string> };          // Toss getUserKeyForGame
  leaderboard?: { submit(boardId: string, score: number): Promise<void> };
}
```
