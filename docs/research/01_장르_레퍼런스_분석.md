- 작성 기준일: 2026-10-06
- 목적: 상업용 싱글플레이 모바일/웹 게임 기획을 위한 레퍼런스 분석 (장르 해부, 차별화 기회, 수치 시작점, 리스크)

## 0. 읽는 법 (신뢰도 표기 규칙)

| 표기 | 의미 |
|---|---|
| **V** (VERIFIED) | 출처 URL이 있고, 해당 페이지에서 직접 확인된 수치/사실. `[S#]`로 하단 Sources에 연결 |

| 미확인 | 시도했으나 근거를 찾지 못함. 숫자를 지어내지 않고 빈칸으로 둠 |

**조사 한계 (중요, 먼저 읽을 것)**
1. WebFetch는 페이지를 소형 모델로 요약해 돌려주며, 일부 결과에서 단위가 틀렸다(예: "1,058 billion won" → 원문은 1,058억 원 = 약 1,058억). 이 문서의 원화 수치는 한국어 원문 기준 "억 원"으로 재정리했다.
2. luckydefenseguides.com(영문 팬 가이드)은 TLS 인증서 만료로 본문을 못 읽었고, 검색 스니펫만 확인했다(해당 값은 E 또는 "스니펫 기반" 표기).
3. Reddit은 WebFetch 접근이 차단되었고, YouTube 검색 도구는 인증이 만료되어 사용 불가였다. 따라서 영상/레딧 기반 정량 정보는 포함하지 못했다.
4. App Store 페이지 일부는 캐시된 스냅샷이다(예: Lucky Defense 미국 페이지가 v2.0.13 / 2024-09-23로 표시). 가격표·평점은 "스냅샷 시점" 값이다.
5. **Lucky Defense의 인-런 소환 비용 시작값/증가폭, 몬스터 처치당 코인, 일반 웨이브 타이머, 타일당 스택 한도는 접근 가능한 자료에서 끝내 확인하지 못했다.** 아래 표에서 "미확인"으로 남겼다.

## 1. 요약 (의사결정용 핵심)

1. **장르 계보**: 스타크래프트 유즈맵(Random Pyramid Defense, Maple Lucky Defense 등)에서 출발해 모바일로 이식. 즉 "랜덤 소환 + 3합성 + 몬스터 수 초과 시 패배"는 **사용자 제작 맵 시절부터의 공유 관행**이다 [S59][S56].
2. **시장 신호**: 한국 모바일 Action&Strategy 카테고리에서 Tower Defense가 **2026년 2월 처음으로 다운로드 1위**(2025-07부터 2위), 매출은 2024-03부터 Strategy 하위 2위(4X 다음) (V) [S2].
3. **Lucky Defense(운빨존많겜)**: 2024-05-23 출시, 약 2개월 만에 누적 300만 DL / $2,000만 (V) [S1]; 2025-04 기준 누적 750만+ DL / 1,200억 원+ (V) [S24]. 111%의 2024년 회사 매출 1,058억 원(전년 +229%, 하이퍼캐주얼사 슈퍼센트 연결 편입 효과 포함 보도 — 게임 단독 수치 아님), 광고선전비 396억 원(영업비용의 39%) (V) [S25][S26] — **성공이 대규모 UA 위에서 만들어졌다**는 점이 핵심.
4. **Random Dice**: 2019-08 출시, 누적 2,156만 DL(2026-06) (V) [S36]. 후속 **Random Dice 2가 2026-08-13 출시**, "가챠 제거"를 전면 내세움 (V) [S36][S39].
5. **Rush Royale**: 2020-12 출시, 1억+ DL / 4.7억 달러+ 누적 매출(2025-12 발표) (V) [S42]. 가장 일관된 불만은 P2W(전설 카드)와 고트로피 매치메이킹 (V) [S47].
6. **가장 강한 공백**: 코어 3종 모두 **PvP 또는 2인 협동**이 중심이다. Lucky Defense 리뷰에서 "강제 멀티플레이, 싱글플레이 옵션을 원함", "잠수 파트너와 10~15분 대기" 불만이 직접 확인된다 (V) [S30]. 확률 신뢰 문제는 2026-02 Lucky Defense 셔플 버그 공시로 실증되었다 (V) [S31][S32].
7. **법적 핵심**: 서울중앙지법 2026-04-02 판결(2024가합115708)은 Lucky Defense 유사작에 대해 **저작권 침해는 전면 기각**(게임 메카닉·UI 등 기능적 요소는 보호 대상 아님), 그러나 **부정경쟁방지법(성과 도용)으로 약 5억 5,700만 원 배상** 인정 (V) [S33][S34]. → 메카닉은 자유롭되 "결합 패키지 + 핵심 성장 메커니즘" 통째 모방은 위험.
8. **수치 시작점(요약, D)**: 6×3=18칸 / 시작 골드 100 / 소환비 15+5n(상한 100) / 기본 희귀도 70-25-5 / 30웨이브(20초) / 보스 10·20·30 / 몬스터 상한 50 / 1런 약 10~11분. 근거와 한계는 7.3절.
