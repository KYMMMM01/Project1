## 3. 알려진 불일치(재개 직후 먼저 고칠 것)

1. `src/game/data/roster.ts`, `src/game/data/strings.ts`, `art/build_jobs.py`가 **이전 id**를 쓴다. v1.0에서 바뀐 것: 적 `flea` → `dryer`, 장난감 `laser_pointer` → `glitter_ball`, `piggy_bank` → `batteries`, `clover_pot` → `purr_pillow`, `maneki_bank` → `sunny_spot`. 재화 `clover` → `purr`(골골). 등급 표기 일반/희귀/영웅/전설/신화 → 꼬마/동네/골목대장/대왕/수호신. 현재 타입 검사는 이 때문에 실패할 수 있다.
2. `기획서_GDD.md` §3~§6·§9~§10은 아직 v0.9 규칙(행운 캡슐, 클로버, 30웨이브, 마릿수 시너지, 같은 전설 합성 → 신화)이다. `명세_전투규칙.md` v1.0에 맞춰 다시 쓴다.
3. `명세_메타.md`는 난이도 3단계·별 3개·신화 해금 전제다. 집사 난이도(0~5단계)·만능 카드·상자 확률표·소탕·28일 출석·주간 컵·냥이 코드로 갱신한다.

## 4. 비평에서 채택한 핵심 변경(v0.9 → v1.0)

- 시너지: 마릿수 3/5/7 → **직업별 서로 다른 유닛 종류 수 2/3/4**(합성과 충돌하지 않게), 수치 ×0.6.
- 수호신(신화)은 **각성으로만**(대왕 + 직업 시너지 2단계 + 골골 3). 같은 대왕끼리 합성 삭제.
- 운 조절: 행운 캡슐(도박형) 삭제 → **털갈이**(골골 1로 같은 등급의 원하는 직업으로 변경, 판당 6회).
- 직접 개입: **레이저 포인터**(경로에 점을 찍어 집중 공격, 5초/재사용 15초), **다음 웨이브 부르기**(남은 시간만큼 생선).
- 자리 싸움: **햇살 칸** 4칸(공속 +20%, 막마다 이동), 위험은 유닛이 아니라 **칸**에 걸림(옮겨서 피한다).
- 구조: 30웨이브 → **24웨이브(6막 × 4)**, 한도 초과는 2초 유예, 보스 제한 50/55/60초.
- 난이도: 체력 배수 3단계 → **집사 난이도 0~5(규칙 추가)**.
- 선행작과 겹치던 요소 제거: 이자·보유 재화 → 피해 전환·한도 증가 유물, 두 번째 재화로 돌리는 도박.
- 수익화: 수익 추정 하향(DAU 5,000에서 월 $3~5K), 보석 사용처(꾸미기·광고 대체), 등급별 카드 비용, 만능 카드, 첫 구매 팩 1,100원, 집사 패스는 3배속·편의만(판 안의 이득 없음), 토스 가격 규칙(11의 배수), 주문 내역 기반 구매 복구, 냥이 코드 백업.
