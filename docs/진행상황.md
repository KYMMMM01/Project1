## 5. 핵심 설계(요약 — 상세는 문서 참조)

- 보드 5×4, 1칸 1유닛, 같은 유닛 2마리 드래그 합성(일반~영웅급까지). 등급 표기: 꼬마 / 동네 / 골목대장 / 대왕 / 수호신.
- 직업 4종(전사·사수·마법·재주) × 등급 5 = 20종. 시너지는 **직업별 서로 다른 유닛 종류 수 2/3/4**.
- 수호신은 **각성으로만**(대왕 + 직업 시너지 2단계 + 골골 12). 털갈이(골골 1)로 같은 등급의 원하는 직업으로 변경.
- 레이저 포인터(집중 공격), 햇살 칸 4칸(막마다 이동), 위험은 칸에 걸림, 다음 웨이브 부르기.
- 24웨이브 = 6막 × 4. 막마다 장난감 3택. 적 한도 초과 2초 유예 또는 보스 제한시간 초과 시 패배.
- 난이도는 집사 난이도 0~5(규칙 추가). 메타: 유닛 카드 레벨, 훈련소, 상자(확률·천장 공개), 미션, 28일 출석, 시즌 패스, 순찰, 소탕, 일일 도전·주간 컵.
- 수익화: 보상형 광고(전체 화면 안의 버튼·홈 카드, 보석 대체 경로) + IAP 11종. 유닛 가챠 없음. 집사 패스는 3배속·편의만.
